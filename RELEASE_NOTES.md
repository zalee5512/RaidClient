## ⚡ Raid Client Launcher v1.0.0

Lanzador y Cliente oficial de **Raid Client** para Minecraft 1.8.9 PvP.

### ✨ Novedades y Características
- **Auto-instalación completa**: Al iniciar por primera vez, descarga e instala automáticamente Vanilla 1.8.9, Forge 1.8.9, librerías nativas de Windows y Java 8 JRE portátil (no requiere configuración manual ni Java previo en la PC).
- **Soporte de Cuentas**:
  - Cuentas No-Premium (Offline) con cambio rápido de nombre.
  - Cuentas Premium oficiales de Microsoft vía OAuth de dispositivo seguro.
- **Raid Client Integrado**:
  - Menú de configuración y ClickGUI con la tecla **Shift Derecho (`RIGHT SHIFT`)**.
  - Editor interactivo de HUD para arrastrar y posicionar módulos.
  - Crosshair personalizado, Hitboxes configurables, Keystrokes animados, ToggleSprint, Fullbright, FPS y CPS counter.
  - Mixins de Minecraft optimizados y compatibles con Forge.

### 📥 Cómo usar
1. Descarga el archivo adjunto `Raid Client Launcher.exe`.
2. Ejecútalo en tu ordenador.
3. Elige tu nombre de jugador y pulsa **"INICIAR RAID CLIENT"**.
